# Creative Direction — Navara × PLATEAU

## 目指す表現
- 現実の東京が未来都市へ変貌する
- 実在する都市が美しい水没ディストピアへ変わる
- 都市全体が発光し、鼓動する
- 目に見えない都市データ（高さ・用途・災害リスク）が光と色になって現れる
- 実在の街並みを幻想的なミニチュアとして見せる

## 価値の優先順位
1. Visual Impact（見た瞬間に驚く・美しい・ゾッとする）
2. Originality（3D地図デモにない独自性）
3. PLATEAU Native（実在データだからこそ成立する）
4. Navara Native（光・大気・雲・影・カメラ・リアルタイム描画）
5. Shareability（Xで共有したくなる静止画・映像）
6. Interactivity

## 評価ルーブリック（100点）
| 評価軸 | 配点 |
|---|---:|
| 第一印象の強さ・美しさ | 35 |
| 実在する都市らしさ | 20 |
| PLATEAUのデータ活用 | 20 |
| 独自性・新規性 | 15 |
| 安定性・再現性 | 10 |

未確認項目は高得点にしない。実画像未確認の評価は「暫定・目視未検証」。

## 作法
- 原則: **静止画の完成度 → 動きの完成度 → インタラクティブ性**（動き自体が核の作品は早期アニメーション試作可）
- Before / After、A/B/C案、昼/夕/夜、東京駅/都庁 の比較を基本動作にする
- 色数を増やす=良い、ではない。配色・明暗・空気感・素材感・発光コントラストで魅せる。虹色グラデーションへの依存は避ける
- カメラ構図を作品の一部とする: 都市全景、地表からの見上げ、ランドマーク中心、低空をかすめる飛行、急上昇、ドラマチックな遠近感。カメラプリセットを用意して比較する
- 「実装できた」と「美しい」を混同しない。チェック観点: 色の調和、光のメリハリ、立体感の維持、ランドマークの認識可能性、1枚絵としての成立、既存3D地図との差の明確さ

## TOKYO // AWAKENING のアートディレクション（初期3案）
- **Cyberpunk**: 紫・ピンク・シアン。夜景ベース、高彩度ネオン
- **Gold Apocalypse**: 黒・金・琥珀。夕景〜夜、金属的な発光と暗い空
- **Holographic City**: 黒・白・ターコイズ。低彩度ベースに単色ホログラム発光、半透明感

## データの誠実さ
- 浸水深などの実属性に基づく表現と、演出としてのフィクションを区別して表示・記録する。物理的・地理的正確性を検証していない演出は「概念表現」として扱う。
