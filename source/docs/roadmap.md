# Roadmap — 実験バックログ（優先順位は仮説。検証結果で自律的に組み替える）

正本は GitHub Issues。本書はその要約と選定理由。

## P0: TOKYO // AWAKENING（最優先・着手中）
現実の東京が光の波で未来都市へ覚醒する。夕景の実景 → ランドマークから光が発生 → 波が建物へ伝播 → 都市全体がネオン発光 → シネマカメラで見せる。
進め方: まず「変貌前/変貌後」の静止画を3アートディレクション（Cyberpunk / Gold Apocalypse / Holographic City）で比較し、最良案に伝播アニメーション（距離ベースの発光タイミング、重心 `_x`/`_y` 利用）を実装する。

## P1: TOKYO UNDERWATER（技術検証中）
東京が美しいディストピアへ沈む。暗雲・雨・霧、水位上昇アニメーション、水面、水没建物の発光、シネマ演出。浸水深属性を再利用（演出であることは明示）。

## P2: CITY X-RAY
スキャン光が都市を横断し、半透明化した建物から高さ・用途・災害リスクが浮かび上がる。輪郭発光＋属性可視化。

## P3: CITY PULSE
都市から光の衝撃波が繰り返し広がる生命体的な鼓動。高さ・密度で色と強度が変化。音楽同期は後段。

## 候補プール（価値順に着手）
- CAMERA LANGUAGE: 映画的カメラプリセット集（見上げ・低空飛行・急上昇等）の整備と構図比較 — 全作品の底上げになるため早期
- POST FX SURVEY: Navaraで使えるポストエフェクト（rainDrop, fogLight, depthOfField, ssr, colorGradingLUT等）の映え調査と採用基準
- AFTER RAIN: 雨上がりの濡れた都市。反射と霧とネオン
- TIME COLLAPSE: 昼夜・天候の劇的遷移を1カットで見せる演出
- TOKYO IN A BOX: 浮遊するミニチュア東京（DOFで tilt-shift 化）
- SKYLINE SYMPHONY: 建物高さを色と音階へ変換するデータアート
- PERSON VIEW: 実在都市の一人称散歩（YUMI/凪キャラ連携の布石）
