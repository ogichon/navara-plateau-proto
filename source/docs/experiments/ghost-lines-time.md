# GHOST LINES — 開業年順の時間蓄積 検証（2026-11-19）

2D検証（`ghost-lines-2d.md`）で条件付き存続となった「開業年順に線が蓄積する時間表現」について、
データで成立するかを検証し、判定材料の静止画を作った記録。

## 方法

- OSM を Overpass API から再取得（東京域 139.53–139.97 / 35.53–35.87）。鉄道 ways 11,338 件（3,537.5 km）、
  河川・運河 ways 1,547 件、駅ノード 806 件。クエリは `ghost-lines-time-src/fetch.py` に記録。
- 開業年表 `ghost-lines-years.csv`：**103 路線定義・210 行**（路線一律の年／駅アンカーによる区間年／
  山手線は環コア 29 区間）。出典は Wikipedia 等の実在ページで裏付け、191 行に URL を併記（うち 71 件は
  本検証で HTTP 200 を実測して補完）。
- 年の規約：**運転系統の開始年ではなく、物理的な線路の開業年**で統一した。共用区間は本線側の年を
  地理で割る（例：京浜東北線区間＝東海道本線 1872／東北本線 1883／上野–東京 1925。埼京線区間＝
  品川線 1885／東北本線 1883）。系統開始年との差異は CSV の note に明記。
- 対応付け：way の `name` を表と照合し、区間年は way 中点に最も近いアンカー駅の群の年を採用。
  山手線は中点を環ポリラインへ投影して区間を決定。
- OSM の `start_date` タグは保有率が **301 / 11,338 件（2.7%）** しかなく、主資料には使えない（補助確認のみ）。

## 網羅率（数字）

| 区分 | ways | 延長 | 備考 |
|---|---|---|---|
| 年を付与できた ways | 7,752（68.4%） | **2,857.3 km（80.8%）** | |
| 無名の側線・留置線（service=yard/siding/crossover/spur） | 3,167 | 592.0 km（16.7%） | 路線ではないので対象外 |
| 名前付き車庫・貨物ヤード内線（番線・留置・コンテナ線等） | 265 | 75.7 km（2.1%） | 同上 |
| 対応付け不能（名前あり） | 約79 | 約6.1 km（0.2%） | 微小な表記ゆれ・訓練線等の残尾 |
| 無名その他 | 75 | 6.3 km（0.2%） | |

**「路線らしい線」だけに限れば網羅率は延長ベースで 99.6%**（2,857.3 / 2,869.8 km）。
件数ベースで低く見えるのは、ヤード・側線が way 数では多いため。

フレーム別累積（対応付け済み延長）：1900年 630.6 km / 1924年 1,041.1 km / **1925年 1,100.4 km（+59.3 km）** /
1960年 1,552.6 km / 2000年 2,668.6 km / 2025年 2,857.3 km。

## 蓄積レンダリング

`ghost-lines-time-{1900,1924,1925,1960,2000,2025}.png`（2520×2400、黒地）。
河川・運河には「開業年」の概念がないため、**全フレームで薄いスレート色で常時敷く**判断にした
（地理の手がかりとしてのみ機能させる）。鉄道は蓄積分を琥珀色、そのフレームの新規分を白寄りに強調。

## 山手線の環は「閉じる瞬間」として読めるか（画を見た所見）

中心部クロップ（`ghost-lines-time-1924-ring.png` / `ghost-lines-time-1925-ring.png`）で比較：

- **1924**：環の東側（上野–秋葉原–神田–東京）が欠け、開いた「C」字として明確に読める。
- **1925**：欠けていた区間が白く現れてループが閉じる。クロップでは**閉鎖は出来事として読める**。
- ただし**全域フレーム（`ghost-lines-time-1925.png`）では環が小さく、山場としては弱い**。1925 年の
  新規分 59.3 km のうち環の旅客区間は約 4 km で、世田谷線・五日市線・山手貨物線北区間なども同じ
  強調色を共有するため、「環だけが閉じる」瞬間にはなっていない。
  → 表現側の条件：**1925 前後で中心部へ寄るカメラ＋年送りの減速＋その間だけ環以外を抑える**演出が要る。
  データ側の問題ではない。
- 副次的な所見：1900 年フレームの「明治の星型ネットワーク」は単体でも絵として強い。蓄積の序盤が
  本編の背骨になり得る。1960 年で地下鉄網が中心を埋め、2025 年で現在の網が完成する弧も素直に読める。

## 一次判定

**データ面は成立。** 路線延長の 99.6% に裏付けのある開業年を付与でき、環の閉鎖過程は区間粒度で
再現できた。時間蓄積という変換ルールは OSM＋開業年表で実行可能。
**表現面は条件付き存続**（2D検証の結論を維持）：成立はデータではなく演出（1925 の山場の作り方）に懸かる。

## 残課題・注意

1. **区間年の近似**：私鉄の細かい段階開業は代表年へ寄せた箇所がある（CSV の note に明記）。
   厳密化するなら路線史料での再検証が要る。
2. **アンカー駅の欠落**：大宮・横浜・千葉・立川・八王子など域外寄りの駅は OSM の駅ノードに無く
   （約120件の言及分）、最近傍アンカーで代替した。全件チェックし、フレーム境界（1900/1924/1925/
   1960/2000/2025）を跨ぐ誤差にならないことは確認済み。ただし区間境界付近の way は±1区間の
   年ずれがあり得る。
3. **仮置き 1 件**：常磐線貨物支線（馬橋支線・北小金支線、計約 7 km）は単独の開業年裏付けが取れず
   本線の 1896 年に準じた仮置き（CSV note に明記）。
4. **現在形状 ≠ 当時の形状**：OSM は現在の線路形状。高架化・地下化で位置が変わった区間
   （上野–秋葉原など）も現在の形状で描かれる。歴史的正確さではなく「現存路線の開業年による蓄積」。
5. **廃線は含まれない**：OSM は現行ネットワークのみ。都電の旧路線網など、消えた線は蓄積に現れない。
   「現存する線だけが残る蓄積」である点はコンセプト側で引き受ける必要がある。
6. ヤード・側線（592 km）は意図的に対象外。車両基地の広がりも時間で見せたい場合は別途
   service 線への年付与が必要。
