## スパイクの問いと答え

### 1. 地理座標のポリラインを任意の高さで描けるか

- 経路は SDK 同梱の `PolylineMeshDesc`（DefaultPlugin の mesh description）。
  `view.addMesh({ polyline: { positions: [{lng, lat, height: 0}...], clampToGround: false,
  height: 60, ... } })` で、地理座標の線を地表 +60 m に描く指定ができる。
  実装確認: 非クランプ時は enhancer に `addHeight = style.height` が渡る（SDK dist の
  baseProps 実測）。点ごとの height は 0 に統一し、二重の持ち上げを避けた。
- **制約（重要）**: `PolylineMeshDesc.buildGeometry` は入力が複数ラインだと例外を投げる
  （"PolylineMesh takes a single line; add one mesh per part of a multi-line"）。
  つまり **1 way = 1 メッシュ**。今回の対象範囲では 1,090 メッシュになる。
  生成所要時間とフレームレートへの影響はページ診断で実測する設計にしたが、未実測。
  本制作に進む場合の本命は、GeoJSON ソース＋ベクタレイヤー（polyline マテリアル＋
  evaluator で年プロパティによる出し分け）への移行で、メッシュ方式はスパイク専用と位置づける。
- 発光: 線は `lit: false`（MeshConfig）で無照明のアルベド＋ `emissiveColor/emissiveIntensity`、
  selective bloom（id `ghost-bloom`、main.ts と同系のパラメータ）を effectIds で適用。
  加算ブレンドはマテリアル設定に露出しておらず、発光は bloom 経由のみ。
  線幅はスクリーン空間ピクセル指定（width 3、maxWidth 7）で、距離で細くならない想定。
  実際に何 px でどう滲むかは未検証。

### 2. 建物をほぼ見えない暗さに落として線だけ読めるか

- 夜シーン（atmosphere 21:00 JST）＋建物色 `0x39404a`（暗い青灰）＋環境光 0.5（青み）＋
  太陽 0.6・影なし＋露出 1.15＋地面 `0x0a0c0f`。v14 以来の「環境光＋露出＋地面ティントで
  真っ黒を回避する」処方の範囲内で組んだ。
- 線側は無照明なので、建物が想定より明るくても暗くても線の視認性自体は照明に依存しない。
  バランス（建物がマッサとして読めるか、線が浮いて見えるか）は**未検証**。実機で見る観点:
  (a) 建物の輪郭がマッサとして読めるか (b) +60 m の線が建物（高さ 60 m 超の塔も多い）と
  交錯して破綻して見えないか (c) 線同士の継ぎ目（way 単位の分割）で途切れて見えないか。

### 3. 年パラメータの切替（1900 / 1925 / 2025）と斜めカメラ

- 全 way を最初に生成し、`handle.update({ visible })` で年以下の way だけ表示する方式。
  再生成なしで即時切替できる。状態別の本数はデータ側で確定済み:
  1900 年 = 245 本 / 1925 年 = 532 本 / 2025 年 = 1,090 本（対象範囲は千代田区＋中央区＋余白、
  経度 139.735–139.800 / 緯度 35.645–35.705）。
- 色分けは 2D アニメの階層を継承: 通常線は琥珀（emissive 1.35）、山手線は一段明るく（1.8）、
  **1925 年の山手線閉鎖区間の way は近白（0xfff1cf、2.4、幅 4）**にして、1925 状態に
  「環が閉じる」出来事がデータとして埋め込まれるようにした。
- カメラ初期位置は東京駅注視、距離 3,200 m、heading 25°、pitch −48°。
  斜めから +60 m の浮きが読めるかは未検証（真俯瞰では浮きは原理的に読めない）。

## データ

- `tools/ghost-lines/extract.py` が 2D パイプラインの対応付け済み成果
  （ghost-lines-anim-src/work/assigned.json、OSM ways × 開業年）を対象範囲で切り出し、
  `public/ghost-lines.json`（250 KB、座標6桁、連続重複点除去済み）を生成。
  元データ: 鉄道 © OpenStreetMap contributors（ODbL）、開業年は ghost-lines-years.csv の検証済み年表。
