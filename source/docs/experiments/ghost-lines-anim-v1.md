# GHOST LINES — 演出つきアニメーション試作 v1（2026-11-20）

静止画検証（`ghost-lines-time.md`）で「表現面は演出に懸かる」となった時間蓄積を、
山場（1925年・山手線の環の閉鎖）が立つよう演出した動画試作。判定材料として作ったもので、
見た目の最終判定は Muse が行う。

## 成果物

- `ghost-lines-anim-v1.mp4` — H.264 / 1680×1600 / 30fps / 38.9 秒 / 10.4 MB
- キーフレーム: `ghost-lines-anim-v1-key-{1924,1925,1960,2025}.png`（動画フレームそのもの）
- フレーム列: `ghost-lines-anim-src/frames/frame-0000.jpg` 〜 `frame-1168.jpg`（JPG q92、約355 MB のため未コミット）
- 生成スクリプト: `ghost-lines-anim-src/anim.py`、取得: `ghost-lines-anim-src/fetch_overpass.py`

## 方法

- データは前回パイプラインをそのまま再実行。OSM は Overpass から再取得（13,691 要素、前回と同数）、
  `defs.py`／`match_render.py` で対応付けし直した。**累積延長は前回と完全一致**
  （1900: 630.6 / 1924: 1,041.1 / 1925: 1,100.4 / 1960: 1,552.6 / 2000: 2,668.6 / 2025: 2,857.3 km）。
- マスターキャンバスは前回静止画と同じ 2520×2400・同じ投影・同じ配色系（黒地、河川/運河は
  スレートで常時、鉄道は琥珀）。前回の「新規分だけ白」の二値ではなく、**開業からの年数で
  明るさが減衰する階層**（新規は白寄り、約22年で琥珀に沈む指数減衰）に変えた。
- タイムライン（全1,169フレーム / 39.0秒）:
  - 1872–1914: 全域、8フレーム/年
  - 1915–1924: 27フレーム/年に減速しつつ、中心（環）へ smoothstep でズームイン
  - 1925: 環の閉鎖区間だけをフラッシュ（0.4秒で立ち上げ、約1.6秒保持）。同時に全体を ×0.82 に落として相対的に浮かせる
  - 1926–1960: 6フレーム/年、冒頭約4秒で全域へズームアウト。フラッシュは 1926 年の頭で減衰
  - 1961–2025: 3フレーム/年。最後に 2025 年の状態を 3 秒保持
- フラッシュ対象は年表で 1925 年の山手線区間 = **38 ways / 4.58 km、中点は経度 139.772–139.775 /
  緯度 35.693–35.712**（上野–秋葉原–神田の回廊）。前回記録の「環の旅客区間 約4 km」と整合。
- 西暦表示は左下に小さく（DejaVu Sans 42px @1680幅）。

## キーフレームを見た所見（一次所見・誇張なし）

- **フラッシュは「印のついた出来事」としては読める。** 1925 キーフレームで閉鎖区間は画面内で
  圧倒的に最も明るく、白く発光して環の東側に立つ。1924 キーフレームと比べると、欠けていた
  位置が埋まったことは確認できる。
- **ただし「環が閉じた」という位相の読み取りは、フラッシュの読み取りより一段弱い。**
  このクロップでは環が大きく不整形で、放射線が同じ画面に密集する。東京の地理を知らない
  視聴者には「何かが光った」が先に立ち、「輪が閉じた」は後からついてくる可能性がある。
- **競合がある。** 年数減衰の配色では 1925 年の他線の開業分（左下の区間など）もクリーム色に
  明るく出る。フラッシュはグロー＋白芯＋全体の減光で一段抜けてはいるが、「画面で唯一明るい」
  状態ではない。
- **1924 の「C の欠け」は前回静止画ほど鋭くない。** 東側には東北本線などの並行回廊が既にあり、
  山手線の欠け部分の周囲が完全に空白ではないため、開き具合が柔らぐ。
- 1900 年の星型はフレーム列でも明瞭（前回所見と一致）。ズーム中間フレーム（1920）の
  フレーミングに破綻はない。動きの滑らかさ自体は静止画では判定できない（MP4 で要確認）。

## 技術的な問題点・残課題

1. **後半の速度**: 1961–2025 は 3フレーム/年で通過するため、開業の多い年は明るい線が
   まとめて点く。動きで見ると点滅的に感じる可能性があり、動画での確認が要る。
2. **アスペクト**: 静止画キャンバス踏襲で 1680×1600（ほぼ正方形）。配信フォーマット
   （16:9 等）への対応はこの試作では扱っていない。
3. ffprobe のフレーム数は 1168（投入 1169、38.93 秒）。実質的な欠落ではないが記録しておく。
4. 年数減衰（τ=22年）は今回の新要素で、前回の二値強調より「新規の瞬間」の対比は弱まる。
   山場の作り込みを進めるなら、1925 前後だけ減衰を止める等の局所制御が候補。
5. 中間生成物（`ghost-lines-anim-src/work/` の osm_raw.json・年次ステート画像・assigned.json、
   約56 MB）とフレーム列は未コミット（前回の生データ非収載の方針に倣った）。再現は
   fetch → match_render → anim の順。

## 再現

```
cd docs/experiments/ghost-lines-anim-src
python3 fetch_overpass.py        # work/osm_raw.json
cp ../ghost-lines-time-src/{defs.py,match_render.py} work/
(cd work && python3 match_render.py)   # work/assigned.json, work/water.json
python3 anim.py                  # ../ghost-lines-anim-v1.mp4 ほか
```
