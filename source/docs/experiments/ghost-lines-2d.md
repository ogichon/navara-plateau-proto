# GHOST LINES 2Dプロット検証（2026-11-09、ディレクター実施・目視判定）

## 方法
OSM（Overpass API）から東京域（139.53–139.97 / 35.53–35.87）の鉄道 11,305 ways・河川/運河 1,544 ways を取得し、黒地に鉄道=暖色・水系=青で等ウェイト描画した（docs/experiments/ghost-lines-2d.png）。描画忠実度に依存しない検証。

## 目視判定（ディレクター）
- **読めたもの**: 放射構造（中心への収束と東西の大放射）、東部の運河グリッド（江東の格子は線画として強い）、荒川・隅田川の帯、東京湾の空白（構図の負空間として効く）。
- **読めなかったもの**: 山手線の「環」。全線等ウェイトでは中心部が一様な網目になり、企画の主役であるはずの環が埋没する。この均一な状態は「データ可視化ポスター」の域で、ゾッとする線ではない。
- **判定: 条件付き存続**。線の素材自体は本物で強い。ただし成立条件は「階層」— 蓄積の順序か量に差をつけること。推奨する具体化: **開業年順に線が蓄積していく時間表現**（環が1925年に閉じる瞬間をクライマックスにする）。研究共通項②「時間の蓄積で物質化」とも一致する。等ウェイトの静止画路線はここで捨てる。
- 副産物: 主役候補として運河グリッドが想定以上に強い。環と運河、どちらを主役にするかは3D試作前のフレーム探索で決める。
