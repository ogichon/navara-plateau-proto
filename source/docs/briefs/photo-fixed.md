# BRIEF-PHOTO — ベースマップは常に写真そのまま（ユーザー決定）

worktree `exp/photo-fixed` で作業。コミットを試み、失敗したら最終報告に明記。デプロイはしない。対象は AWAKENING のみ（UNDERWATER は変更しない）。

## 決定（2026-11-07、ユーザー）

AWAKENING の航空写真は常に素のまま表示する。「ベースマップ確認」トグルは廃止し、案ごとの地面ティントと Before の夕景ティントも全て外す。写真レイヤーは全状態（Before / After / wave）で color=白・opacity=1 に固定する。

## 実装

- 写真の適用処理を「常時 color 0xffffff / opacity 1」に固定する。LOOKS の tint 項目と Before 用ティント（0xd8a878）は写真に使わない（不要になる定義は整理してよいが、他の用途があれば残すこと）。
- 「ベースマップ確認」ボタンとその状態管理・文言（ステータス表示の「ベースマップ確認中」等）を除去する。
- 維持: 建物パレット（base・全 stop 色）、定常発光と倍率、地形 lit 切替、大気 transmittance、雲 haze、環境光、露出、太陽の影設定、雲トグル（BRIEF-CLOUD）。
- ステータス文言から「ベースマップ確認中」が消えることに伴い、表示のテストも追随させる。

## テスト・記録

- 写真が全状態で白・opacity 1 であること、トグル UI が存在しないことをアサーションで固定し、変異で落ちる強度を維持する。
- 全テスト＋ `npx vite build` 成功。
- docs/experiments/tokyo-awakening.md に「ユーザー決定による写真固定とトグル廃止」を追記。
