# BRIEF-TERRA — TERRA NAKED 地形のみ試作

worktree `exp/terra` で作業。コミットを試み、失敗したら最終報告に明記。デプロイはしない。既存ページ（index / awakening / underwater / camera / official）は変更しない。

## 企画（docs/concepts/20261109-concepts.md 案1）

建物も航空写真も剥ぎ、地形と水系だけを闇に浮かぶ彫刻として見せる。変換ルールは「人工物を全て剥ぐ」1つ。実測済みの前提: 東京は西の武蔵野台地（〜56m）から東のゼロメートル地帯（〜-1m）へ落ちる二極地形で、崖線がその境界。

## 実装タスク

新規ページ `terra.html` + `src/terra.ts`。

1. **地形のみのシーン構築を調査して実現する**: 標準の `DefaultPlugin.addDefaultPhotorealScene()` は地理院航空写真ラスター付きで地形を出す。写真なしの「素の地形」にする方法を SDK で確認する（例: シーン構築後にラスター地形レイヤーを写真なし設定へ差し替える／プラグインの部品から手組みする等、実現可能な経路を自分で特定する）。建物レイヤーは追加しない。
2. **地形の見せ方**: 標高が読めるシェーディングを目指す。最低限: (a) 写真の代わりに標高で変化する単色〜2色の地形ティント（低地=暗い青緑、高地=明るい土/岩色など、実装時に決めて記録）、(b) 崖線が読めるよう太陽は低角度（西寄り、夕方）で陰影を強める。Navara の地形レイヤーで標高ティントが不可能なら、到達可能な最善（陰影のみ等）を実装し、不可能だった事項と理由を実験記録に明記する。
3. **画面構成**: 初期カメラは東京全体（23区の落差が一望できる広域・斜め俯瞰）。ゆっくりした自動周回（既存のシネマ周回の流用可）。UI は最小（タイトル、周回ON/OFF、📸キャプチャ）。時刻は固定でよい。
4. **検証可能性**: 描画の自己判定はこの環境では不可能（capture-loop-feasibility 参照）。そのため「タイル取得完了」「地形レイヤーの設定値」「エラーなし」をテストとコードで担保し、見た目の判定は行わないこと。pageshow/pagehide の復帰処理など既存の潜在バグ対策は踏襲する。
