# BRIEF-FIX3 — 地面（ベースマップ）が読めない問題の根本対応（両ページ）

ユーザー目視評価 #2（2026-11-05）: 「まだベースマップ見えないみたい。あと、少し離れると真っ暗になる」。AWAKENING は下限（ティント輝度・環境光0.6・露出1.6）を入れたが、それでも読めないという評価。UNDERWATER は下限未満のパラメータ（ティント 0x27405e／環境光0.35／露出1.25）のままで、スクショでは水面と地面の区別もつかない。下限の微調整を繰り返さず、仕組みを調べて最強のレバーを当てること。この worktree（exp/grade-fix）で作業し、コミットしてください（サンドボックスで失敗したら最終報告に明記）。デプロイはしません。

## 1. 調査（実装前に必須、結果を docs/architecture.md に追記）
`@navaramap/three` / `@navaramap/three-default-descs` の型定義と実装コードを根拠に、次を特定する:
- ラスターレイヤー（航空写真）は lit（太陽・環境光の影響を受ける）か unlit（color × texture のみ）か
- `raster` Desc で color 以外に使える明るさ系項目（opacity / brightness / gamma / contrast / emissive 相当など）の有無と効果
- 環境光（ambient）はラスターに効くか。露出（toneMappingExposure）はラスターに効くか
- 体積雲の shadows は地面（ラスター・地形）を暗くするか
推測で書くな。「コードのどこを見てそう判断したか」を必ず添える。

## 2. 実装（両ページ共通＋個別）
### 共通: 「ベースマップ確認」トグル
- 両ページにボタンを追加。ON の間だけ写真を最大限明るく表示する（ティント 0xffffff、調査で判明した最強レバーが他にあれば併用）。**建物スタイル・時刻・水位・その他のパラメータは一切変えない**。OFF で元の grade に完全復帰。ステータス行に「ベースマップ確認中」と出す。
- 目的: ユーザーが「写真そのものは描画されているか」を切り分けられるようにすること。

### AWAKENING 個別
- After の時刻を 21:00 → **20:00** に変更（BRIEF-FIX2 のエスカレーション条項の実行）。下限（ティント輝度 ≥ 0x51628c 相当／環境光 ≥ 0.6／露出 ≥ 1.6）は維持。建物パレット・Before は不変。

### UNDERWATER 個別
- AWAKENING と同じ下限を適用する: 写真ティントは現行 0x27405e の色相を保ったまま輝度を下限以上へ、環境光 ≥ 0.6、露出 ≥ 1.6。水面の色・透明度、建物スタイル（単一 evaluator・opacity 1）は不変。
- 調査で「雲 shadows が地面を潰す」と分かった場合は shadows のみ OFF にしてよい（coverage 0.85 は維持、判断根拠をドキュメントに残す）。
- 水面 plane を 4000m → **8000m** に拡大する（少し離れると面の外が void になる対策。曲率の継ぎ目リスクは目視確認事項としてドキュメントに明記）。

## 3. テスト
- 両スイートにアサーション追加: (a) 新しい grade パラメータが下限を満たす（適用値で検証、AWAKENING は After 時刻 = 20:00 も） (b) ベースマップ確認トグルの ON で写真系パラメータだけが変わり、OFF で完全復帰する (c) UNDERWATER の plane サイズ = 8000。
- 既存テスト全通過を維持し、`npx vite build` 成功。
