# BRIEF-GROUND（改訂版） — AWAKENING: 地面の暗さを「照明依存から外す」

worktree `exp/ground-lift` で作業。コミットしてください（サンドボックスで失敗したら最終報告に明記）。デプロイはしません。対象は AWAKENING 関連のみ。

## 証拠（ユーザー目視評価 #6・#7、2026-11-07）

1. Gold・覚醒中: 建物の垂直面は夕日を拾うが地面（航空写真）はほぼ真っ黒。
2. Gold・完了・**ベースマップ確認 ON**（写真ティント白＋opacity 1 = 写真の最大表示）でも、地面はほぼ真っ黒。→ ティント起因ではないことが確定。
3. ユーザー: 画角を引くとさらに暗くなり真っ黒になる（距離減光が重なっている）。
4. 副次所見: 建物の面に粒子状ノイズが目立つ（雲 STBN 系の疑い。主対象ではないが、除去できる公開手段があれば併記）。

診断（ディレクター）: 写真は地形上で lit の Lambert。16:30 の太陽高度 +1.5° では水平面の直射 ≈ sin(1.5°) ≈ 3%、環境光 0.15 では不足。さらに大気（aerialPerspective の transmittance / 雲 haze）が距離で減光する。パラメータ微調整の反復は打ち切り、**地面の明るさをシーン照明から切り離す**方向で解決する。

## 調査タスク（コード根拠必須。architecture.md に追記）

- **Q1 地形 lit の切替**: `@navaramap/three-default-descs` の terrain レイヤー説明（desc）に lit 相当の項目があるか。レイヤーの `update()` で実行時に切り替えられるか（Before=lit のまま、After だけ unlit にできるか）。terrain desc の全項目と型を根拠に示すこと。
- **Q2 大気の距離減光**: DefaultPlugin の標準シーンが入れる aerialPerspective エフェクトのハンドル/更新手段はあるか（view の effects 一覧取得、`update` 系 API、プラグインの戻り値）。transmittance / inscatter を個別に切れるか。
- **Q3 雲 haze の距離寄与**: clouds エフェクトの handle は現行コードが保持している。その update で hazeDensityScale を 0 にできるか（0 が許容値か）。

## 実装方針（調査結果に応じて、優先順）

- **方式A（最優先）**: Q1 が可なら、After でのみ地形を unlit にし、地面の明るさはティントだけで制御する。各案のティントは写真が読める明るさに再設定する（現行 Gold 0x927349 より明るい側が目安。ただし Before の地面ティントは変更しない — Before は lit のまま）。After の環境光は建物の影面用に戻す（0.3 目安）・露出は 1.1 目安。太陽 16:30・発光・パレット・haze は現行維持。
- **方式B**: Q1 不可・Q2 可なら、After で transmittance を切り、環境光 0.6・露出 1.35 まで戻す。
- **方式C（フォールバック）**: どちらも不可なら、環境光 0.6・露出 1.35・After haze 0 の組み合わせで最善化し、限界を明記する。
- いずれの方式でも Before は無変更（地形 lit・時刻・ティント・環境光・露出すべて現行値）。ベースマップ確認トグルの意味（ON=写真最大表示）は維持する。
- 建物の粒子ノイズ: 公開手段で消せる場合のみ対処し、無理なら調査結果として残す（雲を切る等の見た目を大きく変える手段は使わない）。
