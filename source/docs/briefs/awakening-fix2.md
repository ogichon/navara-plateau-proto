# BRIEF-FIX2 — AWAKENING: After でベースマップが潰れる問題の修正

ユーザー目視評価 #1 の指摘です。都庁・Gold Apocalypse の After 状態で、航空写真（ベースマップ）がほぼ真っ黒に潰れ、空も真っ黒で、都市が闇に浮いた「島」に見えます。この worktree（exp/awakening）で修正し、テスト・ビルドを通してコミットしてください（コミットがサンドボックスで失敗したら最終報告に明記）。デプロイはしません。

## 原因（ディレクター分析）
- After の grade が「暗い地面ティント × 低い環境光 × 21:00」で写真を乗算的に潰している。Gold は tint 0x55432b / ambient 0.35 / exposure 1.4 で特に暗い。
- v14（src/main.ts）の実証済み夜レシピは tint 0x51628c / ambient 0.6 / exposure 1.7 で写真が濃紺に読める。LOOKS の地面系パラメータがこの実証値から外れているのが主因。

## 修正方針（成果条件で縛る。手段は範囲内で任せる）
1. **建物パレットは不変**：LOOKS の base 色と発光 stops（色・位置）は比較変数なので変更禁止。変えるのは地面・空・光の下限のみ。
2. **地面ティントに明度の下限を設ける**：各案の tint の「色相の個性」は保ちつつ、輝度は v14 夜ティント 0x51628c と同等以上にする（例：look の tint と 0x51628c を混ぜる、または tint を明度方向に引き上げた groundTint を LOOKS に別フィールドで持つ）。
3. **環境光の下限 0.6、露出の下限 1.6**（v14 実証値ベース）。案ごとの個性は下限以上の範囲で残してよい。
4. After の時刻は 21:00 のままで上記で足りなければ 20:00 まで早めてよい。それでも地面が読めない案があれば、パレットを勝手に変えず、ドキュメントに「要ディレクター判断」として記録する。
5. **Before は完全に不変**（17:40 / tint 0xd8a878 / ambient 0.15 / exposure 1.05）。
6. 完了条件（全3案の After で）: 地面の航空写真が読める前提のパラメータになっていること。目視はできないので、パラメータをテストで固定する。

## テスト追加
- scripts/test-awakening.cjs に grade のアサーションを追加：各案の After で (a) 地面ティントの輝度が基準（0x51628c の輝度）以上、(b) ambient >= 0.6、(c) exposure >= 1.6、(d) 建物の emissive stops が従来値と一致（不変の担保）、(e) Before の grade 値が従来通り。
- 既存テスト全通過を維持。
