# BRIEF-CLOUD — 広域で街を覆う「雲形のまだら」の切り分け

worktree `exp/cloud-diag` で作業。コミットを試み、失敗したら最終報告に明記。デプロイはしない。対象は AWAKENING 関連のみ。

## 証拠（目視評価 #10、2026-11-07）

東京駅・Holographic・After・大きく引いた画角: 街全体が暗い茶黒のまだら模様に覆われる。まだらは雲形の輪郭を持ち、海上にもかかる。近景（既定画角）では出ない。一様な黒ではないため、従来の「地面が暗い」とは別の現象。

第一仮説は体積雲: (a) 雲本体がカメラと地面の間に入って地面を覆う、(b) 雲影が何らかの経路で地面を減光する。ただし BRIEF-POLISH-INV では「雲影の表面減光には aerialPerspective irradiance=true が必要（現行 false）」と結論した。unlit 地形との組み合わせで結論が変わるかを含め、再検証する。

## 調査（コード根拠必須。architecture.md に追記）

- **Q1**: 地形 unlit・transmittance false・irradiance false の現行 After で、雲形の暗いまだらが地面ピクセルに生じうる経路を全て挙げる。各経路について「現行設定で効く／効かない」をシェーダ・設定の根拠で判定する。候補: 雲本体のラスタライズ、aerialPerspective の shadow 項（inscatter や最終色への乗算有無）、雲影マップ経由の減光、太陽 CSM（地形は receiveShadow だが unlit で影バッファがどう使われるか）。
- **Q2**: 現在の雲レイヤーの高度範囲（プリセットと現行コードの設定値）と、既定画角（distance 520m・pitch 約-48°）→ 広域（数 km）で雲が画角に入る条件。ユーザーのスクショの画角で雲本体が見える位置関係か。

## 実装（診断トグル）

- AWAKENING に「雲」トグルボタンを追加する。OFF で体積雲エフェクトを**本体・影とも完全に無効化**する（公開手段で最も確実な方法を Q1 の調査で選ぶ。coverage 0 で影が残る等の不完全な方法は不可）。ON で現行設定に完全復帰する。
- 既定は ON（現行の見た目を変えない）。Before / After どちらのグレードでも使え、グレード切替・波・場所切替をまたいでトグル状態を保持する（applyGrade の haze 更新と競合しないこと）。
- トグルは診断用であり、雲の既定の見た目は変更しない。

## テスト・記録

- トグルの OFF 適用・ON 復帰・グレード切替での保持をアサーションで固定し、変異で落ちる強度を維持。既存の全固定値（グレード・影・発光）は不変。
